# 🌐 Personal Profile Website

Welcome to my **Personal Profile Website**! This project is designed to introduce myself, showcase my skills, and present my interests in a modern, clean, and responsive layout.

## 🚀 About the Project

This is a personal portfolio website built using HTML and CSS. It focuses on modern UI/UX design, responsive layouts, and smooth animations to provide a better user experience across different devices.

## ✨ Features

- 🎨 Modern and clean UI/UX design
- 📱 Responsive layout for mobile, tablet, laptop, and desktop
- 📐 CSS Flexbox and Grid layouts
- 🎬 Smooth animations and transitions
- 🧩 Organized HTML and CSS structure
- 💻 Simple and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **CSS Flexbox** – Flexible layouts
- **CSS Grid** – Structured page layouts
- **CSS Animations & Transitions** – Interactive visual effects
- **Media Queries** – Responsive design
